System guide

How BloodConnect supports blood donation workflows.

Learn how donor registration, emergency requests, inventory tracking, and admin monitoring work together in the system.

Donor Registration

Collect accurate donor records before matching.

Donors submit their blood type, contact details, address, availability, and health-related information. Admins can review each donor profile, update lifecycle status, and control whether a donor appears on the patient map.

  • Stores donor profile and blood type information
  • Tracks availability and donation history
  • Lets admins verify map visibility before patients see donor areas

Emergency Requests

Prioritize urgent blood needs.

Patients submit requests with needed blood type, quantity, hospital, and urgency. The admin dashboard helps staff review pending requests, approve or reject them, and coordinate available inventory.

  • Supports urgent request tagging
  • Tracks request status from pending to fulfilled
  • Helps admins coordinate with patients and hospitals

Blood Inventory

Monitor stock levels and availability.

Inventory records show available units by blood type, stock status, and expiry-related information. When requests are fulfilled, stock can be deducted so the dashboard reflects current availability.

  • Displays blood units by type
  • Highlights low or critical stock levels
  • Supports stock updates from successful donations

System Overview

Give admins one place to monitor operations.

The admin dashboard summarizes donor activity, request volume, inventory levels, recent donations, and important alerts. It is designed to help staff see what needs attention quickly.

  • Shows donor and request counts
  • Surfaces urgent and low-stock items
  • Provides profile, lifecycle, inventory, and request tools
